<strong>form.js:</strong> Used to handle form interactions and validation.

<strong>navbar.js:</strong> Used to manage the main navigation bar, like toggling visibility or highlighting active links.

<strong>mobile-nav.js:</strong> Used to handle the mobile version of the navigation menu.

<strong>sticky-footer.js:</strong> Ensures the footer sticks to the bottom when content is not enough to fill the page.

<strong>footer.js:</strong> Manages interactions or dynamic features related to the footer.

<strong>lozad.min.js:</strong> Used for lazy loading images and elements to improve page load performance.

<strong>aos.js:</strong> Used for adding animations when elements scroll into view (scroll-triggered animations).

<strong>lenis.min.js:</strong> Used for smooth scrolling effects.

<strong>ukiyo.min.js:</strong> Used for creating parallax effects on images.

<strong>gsap.min.js:</strong> A powerful animation library for creating advanced animations.

<strong>ScrollMagic.min.js:</strong> Used for creating scroll-based animations, often in combination with GSAP.

<strong>animation.gsap.min.js:</strong> Integrates GSAP animations with ScrollMagic.

<strong>intlTelInput.min.js:</strong> Used for international telephone input fields with country code selection.

<strong>main.js:</strong> Usually contains the main custom JavaScript code for the website, combining various features and interactions.
